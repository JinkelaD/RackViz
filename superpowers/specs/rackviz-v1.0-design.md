# RackViz — 机房设备管理系统 v1.0 设计文档

## 1. 项目概述

参考 RackTables，制作一个机柜设备管理软件。核心目标：清晰展示机柜使用情况、设备资产情况。

**用户规模：** 个人/小团队使用（1-5人）

**版本策略：** 分版本迭代，v1.0 聚焦核心功能

## 2. 技术栈

| 层 | 选择 | 说明 |
|---|------|------|
| 前端 | React 18 + TypeScript + Vite | 生态丰富，拖拽/Canvas组件成熟 |
| UI框架 | Ant Design | 表格/表单/弹窗组件完备 |
| 可视化 | React-Konva | Canvas 2D渲染，支持机柜编辑器和拓扑图 |
| 后端 | Python FastAPI | 高性能，自动OpenAPI文档 |
| ORM | SQLAlchemy + Alembic | 数据库迁移管理 |
| 数据库 | SQLite（默认） | 零配置起步，后续可切换PostgreSQL |
| 样式 | CSS Variables + 自定义暗色主题 | 不依赖Tailwind，独立设计系统 |

## 3. 设计方向

**Aesthetic: Industrial / Utilitarian**

- 暗色终端美学，高数据密度，适合运维场景
- 字体：JetBrains Mono（等宽）+ Space Grotesk（标题）
- 配色：暗底 `#0a0b0f` + 青绿强调 `#3dc9b0`
- 设备类型色：蓝=服务器、青=交换机、琥珀=路由、紫=存储、红=PDU
- 状态色：绿脉冲=在线、红=离线、灰=未配
- 小圆角（2-4px），拒绝"AI审美疲劳"

## 4. 数据模型

### 4.1 核心表（4张）

```
DeviceModel（设备模板库）
├── id
├── name           # H3C R4900 G5
├── manufacturer   # 新华三
├── type           # server/switch/router/storage/pdu/patch
├── height_u       # 占用U数（1-4U）
├── power_watt     # 功率（W）

Rack（机柜）
├── id
├── name           # 机柜01
├── height_u       # 6-42U
├── row            # 网格行位置 (0-23)
├── col            # 网格列位置 (0-23)
├── view           # front/rear

Device（设备实例）
├── id
├── name           # OA服务器
├── device_model_id → DeviceModel
├── rack_id → Rack
├── start_u        # 起始U位
├── end_u          # 结束U位
├── ip_addresses   # 多个IP，分号分隔
├── serial_no      # 序列号
├── function       # 设备功能描述
├── purchase_date  # 采购日期
├── warranty_expire# 质保到期日
├── status         # online/offline/unconfigured
├── power_watt     # 实际功率（可覆盖模板值）
```

### 4.2 关系

```
DeviceModel 1──N Device
Rack 1──N Device
```

## 5. 页面结构

### 5.1 页面清单

| 页面 | 路由 | 功能 |
|------|------|------|
| 机柜图 | `/racks` | 主工作区，网格布局，设备可视化，拖拽布放 |
| 设备台账 | `/devices` | 表格视图，所有设备实例，搜索/筛选 |
| 设备库 | `/models` | 硬件模板 CRUD 管理 |

## 6. 核心交互

| 交互 | 操作 | 说明 |
|------|------|------|
| 拖拽布放 | 从设备库拖到机柜U位 | 放置设备实例 |
| 机柜内移动 | 机柜内拖拽设备块 | 改变U位 |
| 机柜间迁移 | 拖到另一个机柜 | 迁移设备 |
| 双击编辑 | 双击设备/机柜头 | 弹出编辑弹窗 |
| 删除模式 | 切换到删除模式，双击 | 删除设备 |
| 缩放 | Ctrl+滚轮 | 全局缩放 |
| 搜索 | Ctrl+F | 全局搜索定位 |
| 视图切换 | 正视图/背视图 | 切换前后视角 |

## 8. 设计决策记录

| 决策 | 理由 |
|------|------|
| SQLite而非PostgreSQL | 个人/小团队使用，SQLite零配置足够，迁移到PG改一行连接串 |
| 不用Tailwind | 追求独特工业美学，全局CSS Variables更可控 |
| Canvas而非DOM | 大数据量机柜图DOM性能差，Canvas渲染更高性能 |
| 设备库与设备分离 | 模板重用，H3C R4900 G5买多台只需建一次模板 |
| IP存分号分隔字符串 | v1.0简化，不做IP地址管理表 |
| 不做用户权限 | 个人/小团队场景，1.0不需要 |
