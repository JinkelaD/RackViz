# RackViz v2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade RackViz from v1.0 web tool to a Tauri desktop app with pro rack editing, network topology, port/cable management, multi-format reports, and SSH terminal.

**Architecture:** Retain React + FastAPI stack. Phase 0 hardens v1.0 debt (Alembic, placement validation, TanStack Query, background ICMP). Phases 1–5 add features incrementally on the same codebase. Phase 2 wraps the Vite build in Tauri 2 with a FastAPI sidecar. New domain tables (IpAddress, Vlan, PortTemplate, DevicePort, Connection, AuditLog) extend the existing SQLAlchemy models.

**Tech Stack:** React 18, TypeScript, Vite, TanStack Query v5, React-Konva, Ant Design 5, Tauri 2, FastAPI, SQLAlchemy 2, Alembic, APScheduler, dagre, xterm.js, asyncssh, python-docx, weasyprint, pytest, Vitest, Playwright

**Spec:** `docs/superpowers/specs/rackviz-v2.0-design.md`

**Prerequisite:** v1.0 implementation complete (all 20 tasks in `2026-05-27-rackviz-v1.0.md`).

- [ ] **Step 3: Implement `placement.py`**

```python
def u_ranges_overlap(a_start, a_end, b_start, b_end) -> bool:
    return a_start <= b_end and b_start <= a_end

def validate_device_placement(db, rack_id, start_u, end_u, exclude_device_id=None):
    q = db.query(Device).filter(Device.rack_id == rack_id)
    if exclude_device_id:
        q = q.filter(Device.id != exclude_device_id)
    for d in q:
        if d.start_u is None:
            continue
        if u_ranges_overlap(start_u, end_u, d.start_u, d.end_u):
            raise PlacementConflictError(d.id, d.name)
```
